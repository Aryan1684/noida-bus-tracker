SOURCES

Data Sources

Where bus positions, maps, geocoding and infrastructure come from.

Bus data

Live bus-position data is sourced from MARGDARSHI / UPSRTC. The tracker uses that data to display nearby buses and related movement information.

Map data

Maps and map data use MapTiler services with OpenStreetMap-based data. MapTiler requires visible attribution for MapTiler and OpenStreetMap contributors.

© MapTiler · © OpenStreetMap contributors

Infrastructure

Frontend hosting

Netlify hosts the website and provides the form infrastructure used for bus reports. Netlify documents that form submissions can be viewed, exported and deleted by the site owner, and that submission data is stored in its user database.

Backend

The API used by the website is hosted on Render. The frontend sends location coordinates and radius parameters to the API to request nearby bus results.

Browser APIs

Location access and notifications are provided by the user's browser and device. Permission is controlled by the user and operating system.
