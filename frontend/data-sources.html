SOURCES

Data Sources

Where bus positions, maps, geocoding and infrastructure come from.

Bus data

Live bus-position data is sourced from MARGDARSHI / UPSRTC. The tracker uses that data to display nearby buses and related movement information.

Electric fleet map

The fleet map includes buses from the Noida Electric and Greater Noida Electric depots wherever they report GPS positions. Reported destinations include Noida International Airport in Jewar and New Bus Adda in Ghaziabad. A bus with a missing signal or a fix older than two minutes is marked last known. The tracker draws movement between received fixes.

Mapped stops come from the project route catalogue. Road links between them are approximate driving paths from OSRM and OpenStreetMap.

Route references

The June city route list and the November airport timetable use separate route codes. Sector 105, Advant and Panchsheel Balak Inter College identify the expressway corridor. Published itineraries may include locations whose exact boarding points or connecting streets are still unverified.

Map data

Maps and map data use MapTiler services with OpenStreetMap-based data. MapTiler requires visible attribution for MapTiler and OpenStreetMap contributors.

Infrastructure

Frontend hosting

Netlify hosts the website and provides the form infrastructure used for bus reports. Netlify documents that form submissions can be viewed, exported and deleted by the site owner, and that submission data is stored in its user database.

Backend

The API used by the website is hosted on Render. The frontend sends location coordinates and radius parameters to the API to request nearby bus results.

Browser APIs

Location access and notifications are provided by the user's browser and device. Permission is controlled by the user and operating system.
